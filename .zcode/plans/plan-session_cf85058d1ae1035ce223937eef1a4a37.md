# 在线德州扑克（多人 · 局结算联赛制）实施计划

## 总体架构

**单进程 Node.js 服务器**（唯一运行时依赖 `ws`）：HTTP 静态页面 + 同端口 WebSocket。游戏状态在内存，**玩家档案/余额/历史存本地 JSON 文件**（原子写入，防崩溃损坏）。同一份代码支持两种部署：

- **内网（Radmin 等）**：`node server/index.js` → 控制台打印本机所有 IPv4（含 Radmin 网卡），朋友打开 `http://<内网IP>:3000` 即玩；README 附 Windows 防火墙放行命令。
- **公网裸跑**：`PORT=80 node server/index.js`，附 systemd/pm2 说明。
- **Docker**：`Dockerfile`（node:22-alpine）+ `docker-compose.yml`（`./data` 卷挂载持久化档案，自动重启）。

## 身份与档案系统（核心新增）

**F1 风格身份**：`名称 #编号`（如 `max #33`），不注册不登录，相同名称+编号即同一人。**白名单制**：只有登记在册的身份能进入游戏。

- **管理员 max #33**：首次启动生成管理员密码（打印到控制台并写入 `data/config.json`，可用环境变量 `ADMIN_PASSWORD` 覆盖，存哈希）。以 max #33 进入时需输密码，验证后发管理员会话令牌。
- **管理员职能**（大厅管理面板）：添加玩家（名称+编号+初始余额，默认 1000）、手动调整任意玩家余额（±额度+备注，留痕进历史）。
- 普通玩家：输入名称+编号即可，不存在则提示"未登记"。进入后才可见排行榜（避免向公网访客泄露名单）。

**数据文件**（`data/` 目录，JSON，写临时文件+rename 原子落盘，变更后 300ms 防抖保存）：
- `players.json`：`{ key: {name, number, admin, chips, createdAt, history[]} }`，history 条目 `{时间, 房间, delta, 变动后余额, 备注}`。
- `config.json`：管理员密码哈希。
- `active.json`：进行中的对局台账（每手结束保存：房间、玩家、桌上筹码、买入次数）。服务器崩溃/重启时启动即把所有未结算对局**按当前桌上筹码自动结算**（记入历史，备注"服务器重启结算"），账目不丢。

**局结算制**（桌面筹码与余额的对接）：
- 房主建房时设定：每人开局筹码（默认 1000）、小盲、可选前注、行动时限（15/30/60s/关）、是否允许中途再买入。
- 入座即自动买入一份开局筹码；中途破产可再买入一份等额筹码（每手之间）。
- **结算时点**：站起/离开（等当前这手打完）/房间关闭/服务器重启。净输赢 = 结算时桌上筹码 − 买入次数×开局筹码，一次性记入余额，追加历史条目。余额可为负（纯记分板，不阻塞游戏）。
- **走势图**：大厅"战绩"面板——当前余额、累计输赢、场次；纯 SVG 折线图（零轴基线、红绿区、悬停显示每条记录明细）+ 历史明细表；排行榜按余额排序。无第三方图表库。

## 游戏引擎（官方 No-Limit Texas Hold'em，2–9 人）

- 按钮轮转；**heads-up 时按钮即小盲**、翻牌前按钮先行动、翻牌后大盲先行动。
- 盲注/可选前注、四轮下注（翻牌前 UTG 起，翻牌后按钮左侧起）。
- **最小加注规则**：加注幅度 ≥ 当前街最大下注/加注量；不足额全下允许但**不重新打开已行动玩家的加注权**（只能补跟）。翻牌前大盲有 option。
- **边池**：按全下贡献分层，逐层比牌分配；平分池平分，零头给按钮左侧最早座位。
- 牌型评估：7 选 5 取最优（含踢脚、A-2-3-4-5 轮子顺），中文牌型名（皇家同花顺…高牌）。
- 全员全下自动发完公共牌摊牌；无人跟注获胜时不展示底牌；摊牌剩余玩家自动亮牌（在线标准做法）。
- 洗牌用 `crypto.randomInt`；牌局日志（下注/翻牌/结果）进房间聊天流。

## 房间与交互

- 房间码 6 位（去除易混字符）；加入 = 昵称身份 + 房间码；满员或不想玩可**旁观**（见公共牌与彩池，见不到任何底牌）。
- 行动计时：服务器侧倒计时，超时自动过牌/弃牌；断线保留座位（计时器兜底），重进同身份自动回到座位。
- 房间文字聊天 + 系统日志流；**规则手册**常驻按钮，弹窗内含牌型速查表、下注流程、边池/最小加注解释、FAQ，锚点导航快速查看。

## 前端（Vue 3 生产版本地内置 · 深色简约）

- 单页应用，hash 路由：大厅（身份进入 → 创建/加入/战绩/排行/管理面板）与房间两视图。
- 石墨深色背景、低饱和墨绿毡面、金色点缀；纯 CSS 扑克牌（♠♥♦♣ 符号）；发牌/筹码入池/获胜光效等克制动效；**手机端可用**（座位重排、底部固定行动条、加注滑杆+快捷额度）。
- 状态同步：服务器权威，每次变更广播完整快照+事件（底牌仅单发持有者），杜绝前后端不一致。

## 测试与验收

- `node:test` 单测：牌型评估、下注/最小加注/边池、结算数学（含再买入、负债）。
- 集成测试：脚本化 WS 客户端模拟 3 人对局（含全下边池）、站起结算、管理员添加/调整。
- 浏览器实测：进入身份 → 建房 → 加入 → 打牌 → 结算 → 战绩走势图，检查视觉与手机端布局。

## 实施顺序

1. 脚手架 + 服务器引导 + 档案存储（players/config/active + 重启结算）
2. 牌型评估器 + 规则引擎 + 单测
3. 房间/身份/协议/结算 + 集成测试
4. 大厅（身份/创建/加入/战绩走势图/排行/管理面板）
5. 牌桌（座位/下注/聊天/计时/规则手册）
6. 视觉打磨与移动端适配
7. Docker/README 部署文档 + 端到端验证
